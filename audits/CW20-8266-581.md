## 3. Source review (dump `d854a219`)

The crate is cw20-base 0.14 plus:

1. `BALANCES: SnapshotMap<&Addr, Uint128>` with `Strategy::EveryBlock` (`balance` / `balance__checkpoints` / `balance__changelog`)
2. `TOTAL_SUPPLY_HISTORY: Map<u64, Uint128>` written on instantiate (if supply > 0), mint, burn, burn_from
3. Queries `BalanceAt { address, height }` and `TotalSupplyAt { block }`

### Transfer / send (P2)

`execute_transfer` / `execute_send` / `execute_transfer_from` / `execute_send_from` all:

- debit **the same `amount`** from sender (or owner)
- credit **the same `amount`** to recipient
- `send` / `send_from` attach `Cw20ReceiveMsg { amount }` with that same amount

No fee split, no tax destination, no reflection to other holders, no hook that walks `BALANCES` except the two endpoints of the transfer.

This matches cw-plus `cw20-base` v0.14 `execute_transfer` (debit `checked_sub(amount)`, credit `+ amount`). The dump drops the old `InvalidZeroAmount` reject (later cw20-base did the same). Zero-amount is not FoT.

### Snapshots are not rebase

- Current `balance` reads `BALANCES.may_load` (primary map).
- `balance_at` reads `may_load_at_height` only.
- `total_supply` lives in `TOKEN_INFO` and changes only on mint/burn/init.
- `total_supply_at` is a descending range on `TOTAL_SUPPLY_HISTORY` up to `block`. Idle holders are never rewritten.

Live SpaceUSD check (read-only):

| Query | Result |
|-------|--------|
| `token_info.total_supply` | `530000000` (530 human) |
| `total_supply_at` block **27154948** | `30000000` (30 human) — matches instantiate |
| `balance` issuer now | `179474877` |
| `balance_at` issuer height **27154948** | `0` |
| `balance_at` issuer height **30000000** | `179474877` (same as live) |

`balance_at` at the instantiate height returning 0 is **SnapshotMap EveryBlock** semantics: a save at height H stores the *pre-block* value in the changelog. Instantiate credits happen in block 27154948, so “at 27154948” is before that credit. `total_supply_at` uses a different map that **writes the new supply at H**, so it shows 30. This is historical bookkeeping, not elastic supply.

Docs: [CosmWasm SnapshotMap](https://github.com/CosmWasm/docs/blob/main/src/pages/cw-storage-plus/containers/snapshot-map.mdx), [DAO wiki](https://github.com/DA0-DA0/dao-contracts/wiki/How-CosmWasm's-SnapshotMap-Works).

### What the dump cannot prove

- Byte-identical CFG of `953AD60C…` (private `classic_terraport`, missing lockfile).
- Absence of a hidden skim that exists only in the stored wasm and not in the later dump. Wasm **string surface** has no tax/rebase vocabulary and the serde variant lists match the dump, which is strong but not a formal decompile.

## Executive summary

CL8Y DEX is a **mature, security-minded Terra Classic CosmWasm stack**: constant-product AMM, factory governance, multi-hop router, CL8Y fee tiers, post-swap hooks, on-chain FIFO limit orders, and hybrid (book + pool) swaps, plus a Rust indexer and React/Vite dApp. Engineering discipline is high — pervasive checked math + overflow checks, pool-favorable rounding, shared `dex-common` slippage logic, bounded on-chain work, strict on-chain E2E policy, documented invariant→test matrices, and a hardened indexer API (allowlists, rate limits, sanitized DB errors, swap dedup).

The most material gaps cluster into **five themes**:

1. **Quote ≠ execution trust** — hybrid simulations omit CL8Y fee discounts (contract sim) and the Swap page computes `min_received` with `parseFloat` on raw integer strings (precision loss). Users can misread protection on large trades.
2. **Indexer ingestion robustness** — the poller **advances the cursor even when block processing errors**, fetches **at most 100 txs/block** with no pagination, and has **no automatic reorg handling**. These are correctness-critical for an off-chain source of truth.
3. **Governance & process** — single-key factory governance controls fees/hooks/pause/whitelist; no in-contract timelock/multisig; no evidenced third-party audit.
4. **Automation has no enforcement** — no hosted CI, `make test` covers only contracts + frontend unit, no coverage gates, no dependency/SCA scanning, Chromium-only E2E, manual post-deploy smoke.
5. **Operational blind spots** — no Prometheus `/metrics`, shallow health check (no DB/LCD probe), and several O(N) indexer paths that don't scale with pair/trader count.

**Pool-only (v2) launch** remains feasible with the documented ops checklists. **Hybrid-as-default retail UX** still needs the quoting ADR resolved end-to-end (sim parity + honest disclosure), and **indexer ingestion hardening is now the top off-chain blocker** for trustworthy analytics/listings.

## 2. Smart contracts (`smartcontracts/`)

**Toolchain:** `cosmwasm-std` 1.5.11, `cw2`/`cw20` 1.1.2, `cw-storage-plus` 1.2.0, `cw-multi-test` 1.2.0; release profile enables `overflow-checks = true` (`smartcontracts/Cargo.toml:19-44`). All main contracts set `cw2` version on instantiate and implement `migrate` + `ensure_from_older_version`.

### 2.1 Security

| Sev | Finding | Location |
|-----|---------|----------|
| High | Pause traps limit escrow (cancel/claim blocked) — see H3. | `pair/src/contract.rs:513-559` |
| High | Reverting hook = atomic swap failure — see H4. | `pair/src/contract.rs:966-993` |
| High | Single-key governance, no timelock/multisig — see H5. | `factory/src/contract.rs:126-133` |
| High | ~~Router consumes full CW20 balance per hop~~ — fixed **H8** ([#240](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/240)). | `router/src/contract.rs` (R4 hop delta) |
| Medium | Registry `Err(_)` silently charges full fee — see M2. | `pair/src/contract.rs:787-804` |
| Medium | Malicious CW20 callback in-tx (CosmWasm blocks same-contract reentry only); mitigated by code-ID whitelist + adversarial tests. | `pair/src/contract.rs:584-626`; `factory/src/contract.rs:169-180`; `tests/src/adversarial_token.rs` |
| Medium | Router inner hops pass `deadline: None` (relies on single-tx atomicity). | `router/src/contract.rs:368-374` |
| Low | `unreachable!`/`unreachable` for native `AssetInfo` if validation bypassed — prefer `Result` for defense-in-depth. | `pair/src/contract.rs:118-124` |

**Strengths:** checked arithmetic everywhere + k-invariant monotonicity checks (`contract.rs:872-890`); pool-favorable `ceil_div` and LP floor rounding, documented and tested; division-by-zero guards on reserves/spread/bid price; TWAP sampled before reserve mutation (`contract.rs:181-184`); one `CreatePair` per block; sweep excludes reserves + pending escrow (`contract.rs:1716-1721`).

### 2.2 Gas optimization

- Per-swap/limit-batch **Wasm query** to fee-discount registry on every trade (`contract.rs:777-785`).
- `SetDiscountRegistryAll` unbounded message fan-out — M3.
- Book match up to hard cap **256 makers**, each with storage loads (`dex-common/src/pair.rs:19-20`; `orderbook.rs:613`).
- Hybrid reverse sim up to **128 exponential steps** + binary search (`contract.rs:2051-2087`).
- `fee-discount::query_tiers` full-map scan, no pagination (`fee-discount/src/contract.rs:545-554`).
- Good patterns: `Vec::with_capacity` in `limit_placement`; `calc_limit` in factory batch discount.

### 2.3 DRY & readability

- **Discount lookup duplicated**: swap path inlines it (`contract.rs:777-807`) instead of reusing `effective_fee_bps_with_discount_msgs` (`contract.rs:45-86`). This is the root cause of the sim/execute parity gap (H1) — consolidate.
- Pool AMM math duplicated between `execute_swap` and `simulate_hybrid_swap` (intentional parallel paths; drift risk).
- Hook allowed-pair loops near-identical across burn/tax/lp-burn.
- `execute_swap` / `execute_receive` are very long — harder to audit diffs; magic numbers (`MINIMUM_LIQUIDITY = 1_000`, router `MAX_HOPS = 4`).
- Already well-shared: `dex_common::max_spread`, `limit_placement::expand_limit_ladder`, `HybridSwapParams`, hook msg types.

### 2.4 Testing

Strong: ~356 integration `#[test]` (AMM, router, hooks, pause, sandwich), 38 in `limit_order_tests.rs`, adversarial-token + failing-hook suites, proptest for k-invariant/LP/sandwich/escrow-DLL. Gaps: dedicated **3-hop hybrid router** E2E thin (#192); **migrate** only has a factory unit test; **fee-discount** mostly exercised via `lib.rs` not isolated crate tests; **lp-burn-hook** thinner; no `cargo-fuzz` (proptest only).

### 2.5 Feature gaps

Native `AssetInfo` rejected by design (CW20-only); router rejects native hops, wrap-mapper is router-only/optional. No concentrated liquidity / stableswap; constant-product only. No in-protocol farming/governance/voting (out of core scope).

## 3. Indexer (`indexer/`)

### 3.1 Correctness (highest priority for off-chain trust)

- **C1** cursor advances on processing error — `poller.rs:102-120`.
- **C2** ≤100 txs/block, no pagination — `lcd/mod.rs:191-193`.
- **C3** no reorg handling — `poller.rs` + runbook.
- Partial replay idempotency: swaps dedupe on `(tx_hash, pair_id)` via `ON CONFLICT DO NOTHING`; candles/positions/trader aggregates use merge/upsert — reorg/replay without cleanup can leave inconsistent derived state (`swap_events.rs:79`; runbook L12-13).
- Block-time fallback to `Utc::now()` skews candles — M8 (`poller.rs:155-173`).

### 3.2 Security

- LCD error leakage on 502 — H6 (`api/pairs.rs:25-32`).
- Unauthenticated LCD amplification — H7.
- Dynamic SQL via `format!` for sort/interval/lifecycle fragments is **allowlisted in Rust** (safe today) but a latent footgun if a future caller bypasses API validation (`db/queries/traders.rs:61-75`; `candles.rs:90-131`).
- `expect()` on request hot paths: governor config (`api/mod.rs:387`), `best.expect(...)` on empty candidate set (`best_execution.rs:200`) → panic in request task.

**Strengths:** CORS allowlist + prod enforcement; optional `tower_governor` rate limit (default 60 RPS); 30s timeout; query caps (trades ≤200, candles ≤1000, depth ≤100, limit-book ≤100); sanitized `internal_err()`; `RUN_MODE=prod` rejects default LCD list + requires non-empty CORS/DB/factory; dedicated `indexer/tests/security.rs` regression suite; wiremock LCD doubles.

### 3.3 Performance / scale

- Pair-list 24h volume aggregation per request; trader tier sync O(traders) LCD/10min; rolling-volume scan all matching traders/5min — M4.
- Missing index on `limit_order_placements(owner, block_timestamp DESC)` for wallet feeds (`db/queries/limit_order_lifecycle.rs:268-357`).
- Full-scan endpoints: ticker resolution, `cg_pairs`/`cg_tickers`, `list_tokens`, overview asset count — grow linearly with pair count.
- Pool `max_connections(10)`; no env tuning.

### 3.4 Observability

No Prometheus `/metrics`; `/health` returns `{"status":"ok"}` with no DB/LCD probe — H11. `tracing` + `TraceLayer` present; no Sentry/error tracking.

### 3.5 Testing

22 integration files (Postgres-backed) + lib units + proptest (`candle_builder`, ticker segments). **No tests** for poller loop, reorg, >100-tx blocks, or cursor-advance-on-failure behavior. Shared-Postgres parallelism flakes without `flock` + `-j 1 --test-threads=1` (mitigation exists, easy to miss).

## 7. Prioritized recommendations

### P0 — Correctness / trust
1. **Indexer ingestion hardening** (C1–C3): do **not** advance the cursor on block-processing error; paginate `get_block_txs` beyond 100; add height+hash checkpointing and an automated/scripted reorg path.
2. **Hybrid quote parity** (H1): route `HybridSimulation` through the shared discount helper (also resolves the DRY gap), or force honest disclosure when sim omits discounts.
3. **Frontend amount precision** (H2, M10): replace `parseFloat`/`Number` on raw integer strings with BigInt math for `min_received`, withdraw mins, LP sufficiency, and large-amount display.
4. **Governance multisig + external audit** (H5, H9) before mainnet admin moves off an EOA.

### P1 — Production completeness
1. **`make test-all`** (contracts + indexer + frontend + charts + optional E2E flag) and a thin **GitLab CI / mandatory pre-push** gate.
2. **Sanitize 502 LCD responses** (H6) and add **rate-limit-on-by-default** + caps for amplification endpoints (H7).
3. **Observability**: Prometheus `/metrics` + readiness `/health` with DB/LCD probe (H11).
4. **Pause/limit-escrow policy** (H3): either allow cancel/claim while paused or surface a hard banner + docs.
5. **Hook liveness** (H4): consider catch-and-skip semantics (with attributes) or bounded-gas isolation for non-critical hooks.
6. **Coverage gates** (H10) + axe on Swap/Pool/Limits; **dependency/SCA automation** (H9).

### P2 — Important
1. Indexer scale: materialize 24h pair volume; index `limit_order_placements(owner,…)`; cap pair-list `offset`; paginate tokens/CG pairs; batch/cache trader tier sync (M4, M8).
2. ~~Router hop accounting = delta balance, or document donation risk (H8).~~ **Done ([#240](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/240)).**
3. Registry-error fee policy (M2) and cap/deprecate `SetDiscountRegistryAll` (M3).
4. Swap outage banner + `simQuery.isError` UX (M1); IL disclosure on `/pool` (M6).
5. Firefox/WebKit smoke E2E (M7); wire post-deploy smoke into `qa-verify-deploy`; emit `wasm-checksums.txt` in `optimize.sh`.

### P3 — Polish
1. Listbox keyboard/typeahead (M5); modal scroll-lock + focus-restore.
2. Split mega-pages; remove dead `framer-motion`; consolidate dual test helpers; tune polling for mobile.
3. i18n; in-app onboarding tour; ADR 0002 renumber; token-list schema validation; document Python vs TS swarm roles.

## Executive summary

CL8Y DEX is a **mature Terra Classic CosmWasm stack**: constant-product AMM, factory governance, multi-hop router, CL8Y fee tiers, post-swap hooks, **on-chain FIFO limit orders**, and **hybrid (book + pool) swaps**, plus a **Rust indexer** and **React/Vite dApp**. **Pool-only (v2) swaps** are the most production-ready path: contracts, indexer, frontend, and CI E2E align well.

The largest **product and safety gaps** remain:

1. **Quote ≠ execution for hybrid** — LCD/router simulation paths ignore or under-model the limit book; users can misread expected output.
2. **No unified “best execution” product** — hybrid splits are manual or per-hop indexer hints, not a signed, globally optimal route.
3. **Operations** — tracing-only observability, no Prometheus; incident/runbook coverage is partial; wasm CI vs optimizer artifact policy still needs operator discipline.
4. **User expectations vs Terraport-class DEXes** — no staking/farming/governance UI; native-only pairs still rejected at contract layer (wrap path exists in deploy/UX but is not first-class in core `AssetInfo`).

**Pool-only launch** is feasible with documented ops checklists; **hybrid-as-default retail UX** still needs disclosure, quoting ADR, and stronger multihop E2E confidence.

## 3. Security gaps

| Area | Severity | Finding | Mitigation / tracking |
|------|----------|---------|------------------------|
| **Governance key** | Critical | Single factory `governance` controls fees, hooks, pause | Multisig/DAO required for mainnet (`security-model.md`) |
| **Hybrid quote mismatch** | High | Users trust simulation/display that omits book leg | Disclosure ([#105](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/105)), ADR ([#108](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/108) epic) |
| **Trusted router / trader field** | High | Mitigated by fee-discount trusted-router list | Document in launch checklist |
| **Malicious CW20** | High | Mitigated by code ID whitelist | Operators must not whitelist unknown code IDs |
| **Hook griefing** | Medium | Reverting hook blocks swap | Only audited hooks; bounded gas |
| **Indexer API** | Medium | Rate limits, CORS, allowlists tested | Operator must set `CORS_ORIGINS`, `RUN_MODE=prod` + non-default LCD on mainnet |
| **Frontend** | Medium | No prod source maps (good); risk modal for NFA | [#117](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/117), [#138](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/138) |
| **Secrets in git** | Medium | `.env.example` only | `docs/operator-secrets.md` |
| **Supply chain** | Medium | `@goblinhunt/cosmes` fork + patch-package | Pin/review on upgrade |
| **Third-party audit** | High (process) | Self-review matrices in-repo | External audit not evidenced in repo |
| **Pause + cancel (L6)** | Medium | Users cannot cancel limits when paused | Banner on `/limits` ([#12](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/12) class) |
| **E2E dev mnemonic** | Low (local) | Hard-coded local dev wallet in deploy/E2E | Never use on mainnet |

**Strengths:** Invariant matrix in `contracts-security-audit.md` and `indexer-invariants.md` with test mapping; strict E2E policy ([#201](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/201)); factory rate limits and pending-pair semantics documented.

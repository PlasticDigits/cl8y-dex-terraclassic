## Invariants (summary)

1. **Naming:** Use **TradingView lightweight-charts** or **lightweight-charts** — not the hosted **TradingView Widget** product ([docs/frontend.md](../docs/frontend.md)).
2. **Non-negative USD scale:** The candlestick pane’s right price scale must not show autoscale **below zero** or invent dead space **below the lowest visible candle low** ([#151](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/151)).
3. **Volume bars:** Histogram uses **human** quote volume first (`volume_quote` ÷ quote decimals); if quote is zero, **human** base volume ([#150](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/150), [#564](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/564)). Do not plot raw 18-dec integers. Invert does not flip volume (**C543-8**).
4. **Indicators:** MA / RSI toggles **do not recreate** the chart. After the first `createChart`, `syncPriceChartIndicatorOverlays` adds/removes line series on pane 0 and adds/removes the RSI pane (`addPane` / `removePane(2)`) so QA toggles always match UI state ([GitLab **#150**](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/150)). Regression: stub contract tests ([#227](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/227)). Pure math stays in `priceChartIndicators.ts`; sync logic: `priceChartLightweightIndicatorSync.ts`.
5. **Fullscreen:** Uses **`requestFullscreen`** on the chart card root; listen for **`fullscreenchange`** for aria / button label (`Expand chart to fullscreen` / `Exit chart fullscreen`). Playwright mocks the Fullscreen API in **`installPriceChartFullscreenMock`** ([#228](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/228)).
6. **Headline price:** **Last** beside the title prefers indexer tape USD (`tapeLastPriceUsd` prop from `resolveTapeLastPriceUsd` / `price_usd` — **not** raw `trades[].price`, [#522](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/522)), else last candle close ([#149](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/149)). See [`AGENTS_INDEXER_PAIR_PRICE_USD.md`](./AGENTS_INDEXER_PAIR_PRICE_USD.md). **#524 / #543 UI invert:** parents may pass **display** USD (`resolveDisplayTapeLastPriceUsd`) and `displayInverted` so UST1-as-base pairs show the other token. USD candles use `applyChartDisplayInvert` = per-bar **`invertUsd`** (`factory_usd / human`), **never** `invertOhlc` `1/x` on a USD series. Adaptive `priceFormat` so sub-cent USD is readable. Indexer series stay factory-oriented. See [`AGENTS_FRONTEND_TRADE_PAIR_INVERT.md`](./AGENTS_FRONTEND_TRADE_PAIR_INVERT.md), [`AGENTS_FRONTEND_USD_CANDLE_INVERT.md`](./AGENTS_FRONTEND_USD_CANDLE_INVERT.md).
7. **Tests:** Default Vitest uses **`lightweightChartsJsdomMock`** for fast React/indexer wiring — extend it when adding series APIs (`createPriceLine`, `priceScale`, etc.) and update **contract** tests when changing `createChart` / pane layout options ([#227](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/227)). Library-backed init, `setData`, indicators, volume fallback, and autoscale belong in **`*.charts.test.{ts,tsx}`** (`npm run test:charts`, [#211](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/211)). **Large-candle** (≥500 rows, CI soak 2000) and **USD autoscale with real `getVisibleLogicalRange()`** (after `setVisibleLogicalRange`) live in `priceChartLightweightRealLibrary.charts.test.ts` — reuse **`chartRealLibraryHarness.ts`** ([#229](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/229)). Pure clamp math stays in **`priceChartPriceScale.test.ts`** ([#151](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/151)). **Playwright** ([**#228**](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/228)): `e2e/price-chart-smoke.spec.ts` asserts **`price-chart-lightweight-canvas`** + child `canvas`, mocked **fullscreen** aria toggles, and `/trade` canvas under strict stack — no pixel/color assertions. Prefer **`data-testid`** over canvas pixel assertions; use real canvas only where the library API is under test.
8. **Plot height in `/trade`:** `PriceChart` is **`h-full flex flex-col min-h-0`**; the plot uses **`flex-1 min-h-0`** with **`min-h-[min(52vh,280px)]`** (not a fixed tall block) so parents with **`overflow-hidden`** do not clip the canvas ([#151](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/151)).
9. **Post-layout sizing:** After `createChart`, **`PriceChartLightweightCanvas`** passes **`layout.panes.enableResize: false`** and calls **`applySize`** on a **double `requestAnimationFrame`** so width/height match the container after flex/grid layout ([#151](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/151)). **`ResizeObserver`** on the container re-runs `applySize` on resize. Regression: stub contract + lifecycle `PriceChartLightweightCanvas.test.tsx` ([#227](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/227), [#225](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/225)) + `PriceChartLightweightCanvas.charts.test.tsx` ([#211](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/211)).
10. **Async init guard:** **`chartInitIdRef`** drops stale `import('lightweight-charts')` completions and calls **`chart.remove()`** on abandoned instances; unmount-before-resolve must not throw ([#148](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/148), [#225](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/225)).
11. **Timeframe switches ([#148](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/148)):** Candles query uses **`keepPreviousCandlesForIntervalSwitch`** (`priceChartCandlesPlaceholder.ts`) so **interval** changes do **not** unmount the canvas, but **pair** changes drop placeholder data and remount via **`key={pairAddress}`** (aligns with [pair switch](./AGENTS_FRONTEND_TRADE_PAIR_SWITCH.md)). Only the **first** load shows **Loading chart…**; interval refetches show **`price-chart-interval-loading`**. **`createChart` runs once** per canvas mount; interval updates use **`setData`**. Regression: `PriceChart.test.tsx` — *reuses one chart instance across many interval switches*; *remounts chart on pair switch and keeps interval switches responsive*.
12. **Time-scale zoom on live refetch ([#336](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/336) / [#705](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/705)):** `refetchInterval: 30_000` on candles must **not** call **`timeScale().fitContent()`**. Background updates go through **`priceChartLightweightSeriesSync.ts`**: **`update`** only for the last bar and/or appended bars; **`setData`** on first load, interval switch, truncated history, or a rewrite of any historical bar (pair invert **#524** — same times, new OHLC; `update` on an older bar throws `Cannot update oldest data`). **`fitContent()`** is allowed on **initial mount**, **indicator toggle**, and **interval switch** (after the new series `setData`, when first-bar time changes — [#705](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/705)). Sliding newest-N at the same interval must **not** refit. Pass **`interval`** into `PriceChartLightweightCanvas`. Regression: `priceChartLightweightSeriesSync.test.ts`, `PriceChartLightweightCanvas.test.tsx` — *background data refresh does not call fitContent*; *interval setData calls fitContent*. Indexer GET is newest-N chronological: [`AGENTS_INDEXER_CANDLES_NEWEST_N.md`](./AGENTS_INDEXER_CANDLES_NEWEST_N.md).
13. **Indexer candle trust boundary ([#226](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/226)):** **`indexerCandlesToChartPoints`** / volume mapping **drop** bad rows (see module comment in `priceChartCandles.ts`); never pass `NaN`/`Infinity` to lightweight-charts. Pure tests only in `priceChartCandles.test.ts` — no library import.
14. **Stale pair `getCandles` ([#226](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/226)):** Query key `['candles', pairAddress, interval]` must win over out-of-order HTTP; regression mocks delayed pair A after fast pair B. Add a ref guard in `PriceChart` only if that test fails without it.
15. **Accessibility ([#214](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/214)):** Canvas wrapper stays **`aria-hidden`**; AT gets interval + last price from `PriceChart` region + `aria-live`. Set **`layout.attributionLogo: false`** and render **`data-testid="price-chart-tradingview-attribution"`** on `PriceChart` so Apache NOTICE is met without focusable `#tv-attr-logo` inside the hidden plot. See [`AGENTS_FRONTEND_A11Y_CI.md`](./AGENTS_FRONTEND_A11Y_CI.md).

## Rules of thumb

1. **Never** point the swarm at public RPC/LCD or mainnet/testnet — it exits unless LCD reports `localterra` and optional `VITE_NETWORK=local`.
2. **Do not** commit `SWARM_BOT_MNEMONIC` or generated mnemonics; CI and gitleaks expectations match other wallet docs ([`AGENTS_BUNDLE_DEV_WALLET.md`](./AGENTS_BUNDLE_DEV_WALLET.md)).
3. **Funding:** Prefer the built-in idempotent path (`test1` bank sends + CW20 `Mint` over **all** factory tokens). Do not shrink mint coverage to “only CL8Y/LUNC_C/USTC_C” unless product explicitly changes #119. Default `SWARM_*` top-ups are **10×** genesis/deploy seeds ([#372](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/372)); after genesis changes run **`make reset`** ([`AGENTS_QA_FRESH_VOLUMES.md`](./AGENTS_QA_FRESH_VOLUMES.md)).
4. **LP decimals / bootstrap:** On-chain LP share CW20 metadata uses **18 decimals** (`LP_TOKEN_DECIMALS`); factory **`CreatePair`** and empty-pool first mint reject either asset CW20 with **`decimals > 18`** — see [**#124**](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/124), `dex_common::pair`, and [`docs/contracts-terraclassic.md`](../docs/contracts-terraclassic.md).
5. **Liquidity guards** in `liquidityGuards.ts` are heuristics aligned with default `deploy-dex-local` reserves; if you change seed liquidity in the deploy script, revisit constants and the README table together.
5b. **Python QA swarm LP (#293):** `scripts/bots/launch-swarm.sh` runs `bootstrap-swarm-liquidity.sh` once, then starts **three** `--worker lp N` processes that `provide_liquidity` proportionally (`scripts/bots/swarm_liquidity.py` mirrors `liquidityGuards.ts`). Swap-only workers skip pairs below `BOTS_MIN_RESERVE_PER_SIDE` (default **10M** raw units). Hub pairs **EMBER/CORAL**, **TOPAZ/ONYX**, **ONYX/CORAL** get an extra deepen on bootstrap for OE-1 swap checklist quotes. The TypeScript `@cl8y-dex/localnet-trading-swarm` package also raised `add_liquidity` profile weights — use **both** layers when reproducing “swarm was running” QA. Verification: `make verify-issue-293` (unit tests + live indexer after `make swarm-bootstrap-liquidity && make swarm-launch`). **OE-1 reciprocal check** uses `pool_only=true` on hub pairs (≤5% deviation); global `route/solve` asymmetry (e.g. EMBER→CORAL 3-hop arb vs CORAL→EMBER direct) is **expected** on LocalTerra lopsided deploy — not a Swap decimal bug ([#293](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/work_items/293)). **Slippage enrichment** (`slippage_percent`, `spot_amount_out`) requires a **single** quote-asset row per symbol in the indexer DB — stale duplicate `USTC-C` rows from a prior deploy without `--fresh` omit enrichment; use `make setup-cloud-localterra --fresh` when `make verify-issue-293` [3c] fails with missing slippage fields.
6. **Local automation** (reference job `localnet-trading-swarm`): `cd packages/localnet-trading-swarm && npm ci && npm run test:run` (no chain). See [docs/testing.md § CI](../docs/testing.md#ci).
7. **Factory `create_pair`:** on-chain, **at most one** `CreatePair` may start per block height (see [`docs/security-model.md`](../docs/security-model.md#createpair-rate-limit-and-pending-state), GitLab [#121](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/121)). Loops that create many pools must **advance the block** between creations. Factories charge a governance-set **uluna creation fee** to treasury (default **100 LUNC**; GitLab [#276](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/276)); `deploy-dex-local` instantiates with that real default fee and attaches it on every `create_pair` (treasury == deploy address, so the fee returns to the deployer). The swarm only swaps / provides liquidity, never `create_pair`, so it is unaffected; set `LOCAL_PAIR_CREATION_FEE_ULUNA=0` for a fee-free local chain (GitLab [#318](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/318)).
8. **Indexer CORS vs Vite `Origin`:** `http://localhost:5173` and `http://127.0.0.1:5173` are different browser origins. If `CORS_ORIGINS` on the indexer omits the one you use, limit **cancel ID** auto-fill after placement fails (console: `[limit-place] indexer poll failed:`). See [GitLab **#131**](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/131) and [`docs/frontend.md` § Local dev indexer CORS](../docs/frontend.md#local-dev-indexer-cors).
9. **Router `execute_swap_operations` gas:** [`src/gas.ts`](../packages/localnet-trading-swarm/src/gas.ts) must keep **`SWAP_GAS_BUFFER` (and hop padding / floor constants)** aligned with [`frontend-dapp/src/utils/constants.ts`](../frontend-dapp/src/utils/constants.ts) so bot broadcasts match wallet UX ([GitLab #115](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/115), [`skills/AGENTS_TERRACLASSIC_GAS.md`](./AGENTS_TERRACLASSIC_GAS.md)).
10. **Limit placements vs cancels:** after a cancel tx, integrators should not treat `GET .../limit-placements` as including that `order_id` once the indexer has ingested `cancel_limit_order` (see [GitLab **#135**](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/135), [`docs/indexer-invariants.md`](../docs/indexer-invariants.md)).
11. **Wallet history / CSV (fills, cancels, swaps):** [GitLab **#163**](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/163), [`skills/AGENTS_FRONTEND_ORDER_HISTORY.md`](./AGENTS_FRONTEND_ORDER_HISTORY.md), trader routes in [`docs/indexer-invariants.md`](../docs/indexer-invariants.md).

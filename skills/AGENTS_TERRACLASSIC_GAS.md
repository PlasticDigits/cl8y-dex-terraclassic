## Rules of thumb

1. **Do not assume LCD simulation** matches what the user’s extension broadcasts (`Station`, **Terra Classic Keplr**, …); the dApp supplies an explicit `Fee` object.
2. **If `gasUsed` from a failed tx is known**, new defaults must exceed that with margin (wasm + storage variance on Classic is not tight).
3. **Keep CLI and dApp aligned**: repo scripts use `--gas-adjustment 1.3` on `terrad`; **`SWAP_GAS_BUFFER` is 1.3** in the dApp and in `packages/localnet-trading-swarm/src/gas.ts` so scripted swaps and the UI do not diverge from that default.
4. **Changing `SWAP_GAS_BUFFER`** scales all hop counts; re-run unit tests and, when possible, a LocalTerra swap happy path.
5. **Limit / bid + insufficient fee ([GitLab #127](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/127)):** Place Limit sends **`increase_allowance`** then CW20 **`send`** with `place_limit_order`. If **`VITE_GAS_PRICE_ULUNA`** is far below Station/chain minimum, **`Fee.amount`** is tiny while **`gas_wanted`** is still correct (e.g. **200k** on allowance → ~**3,000 uluna** paid vs **5,665,000 uluna** required). **`effectiveGasPriceUluna()`** floors at **28.325**; **`scripts/deploy-dex-local.sh`** writes **`VITE_GAS_PRICE_ULUNA=28.325`** into **`.env.local`**.
6. **Station extension (all networks):** Station’s Keplr shim mishandles **`signDirect`** (false “User denied”, fee rewrite). Mitigations ([#127](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/127), [#208](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/208), [#134](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/134)): universal **`broadcastTerraExecuteContracts`**; **`applyStationKeplrShimSignDefaults()`** + **`ensureStationLocalNetworkRegistered`** (always **`addNetwork`**) / **`experimentalSuggestChain`** on connect; cosmes patch (**per-sign `preferNoSetFee`**, post-sign guard vs **`stdDoc.fee`**); **`StationController`** → **amino always** for extension. See [`AGENTS_FRONTEND_STATION_SIGNING.md`](./AGENTS_FRONTEND_STATION_SIGNING.md). **Pool-only CW20 swap** gas is **`gasLimitForExecuteSwapOperations(1)`** (**830k**), not legacy **600k** ([#115](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/115)). Confirm **`npm ci`** (`cosmesPatch127.test.ts`). If the guard throws (or **`humanizeTerraTxError`** mentions **`3000uluna`**), disconnect/reconnect Station — do not diagnose from node **`insufficient fees`** or misleading **`out of gas`** alone when the wallet halved the signed fee.
7. **LocalTerra wallet matrix ([GitLab #235](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/235)):** When verifying gas/fee fixes on **LocalTerra** ([#127](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/127)), use **Terra Classic Keplr** and/or the **dev/simulated wallet** — **not Terra Station** (Station built-in **`localterra`** gas step is stale and ignores dApp overrides; see [docs/frontend.md § Station extension signing](../docs/frontend.md#station-extension-signing)). **Terra Station P0** (swap, limits, bids, wrap/unwrap) belongs on **columbus-5** only. See [`AGENTS_FRONTEND_STATION_SIGNING.md`](./AGENTS_FRONTEND_STATION_SIGNING.md).

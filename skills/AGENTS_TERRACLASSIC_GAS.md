## Rules of thumb

1. **Do not assume LCD simulation** matches what the user’s extension broadcasts (`Station`, **Terra Classic Keplr**, …); the dApp supplies an explicit `Fee` object.
2. **If `gasUsed` from a failed tx is known**, new defaults must exceed that with margin (wasm + storage variance on Classic is not tight).
3. **Keep CLI and dApp aligned**: repo scripts use `--gas-adjustment 1.3` on `terrad`; **`SWAP_GAS_BUFFER` is 1.3** in the dApp and in `packages/localnet-trading-swarm/src/gas.ts` so scripted swaps and the UI do not diverge from that default.
4. **Changing `SWAP_GAS_BUFFER`** scales all hop counts; re-run unit tests and, when possible, a LocalTerra swap happy path.
5. **Limit / bid + insufficient fee ([GitLab #127](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/127)):** Place Limit sends **`increase_allowance`** then CW20 **`send`** with `place_limit_order`. If **`VITE_GAS_PRICE_ULUNA`** is far below Station/chain minimum, **`Fee.amount`** is tiny while **`gas_wanted`** is still correct (e.g. **200k** on allowance → ~**3,000 uluna** paid vs **5,665,000 uluna** required). **`effectiveGasPriceUluna()`** floors at **28.325**; **`scripts/deploy-dex-local.sh`** writes **`VITE_GAS_PRICE_ULUNA=28.325`** into **`.env.local`**.
6. **Station extension (all networks):** Station’s Keplr shim mishandles **`signDirect`** (false “User denied”, fee rewrite). Mitigations ([#127](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/127), [#208](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/208), [#134](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/134)): universal **`broadcastTerraExecuteContracts`**; **`applyStationKeplrShimSignDefaults()`** + **`experimentalSuggestChain`** on connect (mainnet + legacy local); cosmes patch (**per-sign `preferNoSetFee`**, post-sign guards, amino re-sign retry on LocalTerra); **`StationController`** → **amino always** for extension. See [`AGENTS_FRONTEND_STATION_SIGNING.md`](./AGENTS_FRONTEND_STATION_SIGNING.md). **Pool-only CW20 swap** gas is **`gasLimitForExecuteSwapOperations(1)`** (**830k**), not legacy **600k** ([#115](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/115)). Confirm **`npm ci`** (`cosmesPatch127.test.ts`). If the guard throws (or **`humanizeTerraTxError`** mentions **`3000uluna`**), reconnect Station — do not diagnose from node **`insufficient fees`** or misleading **`out of gas`** alone when the wallet halved the signed fee.
7. **LocalTerra wallet matrix:** When verifying gas/fee fixes ([GitLab #127](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/127)), test **Station** and **Terra Classic Keplr** (both already use `experimentalSuggestChain` on extension connect for Keplr; Station needed the extra path in rule 6). Do not assume one passing wallet implies the other.
8. **Limit escrow vs wallet balance ([GitLab #130](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/130)):** before `increase_allowance` + `place_limit_order`, the UI must gate on CW20 balance (see [`limitOrderEscrowBalanceGate.ts`](../frontend-dapp/src/utils/limitOrderEscrowBalanceGate.ts), [`docs/limit-orders.md` § dApp retail form](../docs/limit-orders.md#dapp-retail-form-wires-invariants)). Otherwise users pay gas on allowance then fail `transfer_from` with no escrow tokens.
9. **Limit place: two native fees ([GitLab #132](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/132)):** the same UI path must require **uluna** ≥ sum of the two `Fee.amount` estimates (allowance tx + place tx) before broadcasting `increase_allowance`, or users burn the first fee when the second cannot sign/pay. See [`limitOrderNativeGasBalanceGate.ts`](../frontend-dapp/src/utils/limitOrderNativeGasBalanceGate.ts) and `estimateLimitOrderPlaceSequenceUlunaFeesTotal` in [`transactions.ts`](../frontend-dapp/src/services/terraclassic/transactions.ts).
10. **Pool add: three native fees ([GitLab #147](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/147)):** CW20/CW20 **Provide Liquidity** must require **uluna** ≥ sum of **three** `Fee.amount` estimates (`increase_allowance` ×2 + `provide_liquidity`) before broadcasting the first allowance — same pattern as [#132](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/132). See [`provideLiquidityNativeGasBalanceGate.ts`](../frontend-dapp/src/utils/provideLiquidityNativeGasBalanceGate.ts) and `estimateProvideLiquidityCw20SequenceUlunaFeesTotal` in [`transactions.ts`](../frontend-dapp/src/services/terraclassic/transactions.ts). **Rollback:** if `provide_liquidity` fails after allowances, [`pair.ts`](../frontend-dapp/src/services/terraclassic/pair.ts) runs **both** `decrease_allowance` msgs via **`executeTerraContractMulti`** (one fee), not two separate txs.
11. **Factory governance gas ([GitLab #122](https://gitlab.com/PlasticDigits/cl8y-dex-terraclassic/-/issues/122)):** Per-pair admin messages (`SetPairFee`, `SetPairHooks`, `SweepPair`, …) must use **O(1)** on-chain lookups (`pair_addr_reg`), not linear scans over all pairs. Full-registry iteration remains only for intentional broadcast/pagination paths; see [`docs/contracts-terraclassic.md` § Factory storage & upgrades](../docs/contracts-terraclassic.md#factory-storage--upgrades). Indexers querying the factory over LCD should paginate pair discovery — [`docs/indexer-invariants.md` § Factory LCD](../docs/indexer-invariants.md#factory-lcd-pair-enumeration-vs-governance-gas-agents).

## When the user references another repo for “how gas works”

Paths differ by machine. Compare **patterns** (simulate vs fixed gas, adjustment multipliers), not copy-paste numbers, unless the same contracts and message shapes are guaranteed.
